# theme_agData.

ggplot theme.

## Usage

``` r
theme_agData(
  x,
  bgFill = "white",
  lineColor = "grey90",
  lineSize = 0.75,
  stripFill = "white",
  caption.adj = 1,
  ...
)
```

## Arguments

- x:

  ggplot

- bgFill:

  background fill color

- lineColor:

  color of axis lines

- lineSize:

  border line size

- stripFill:

  strip background color

- caption.adj:

  hjust for the caption

## Value

ggplot with agData theme
