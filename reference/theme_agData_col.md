# theme_agData_col.

ggplot theme.

## Usage

``` r
theme_agData_col(
  x,
  bgFill = "white",
  lineColor = "grey90",
  linesize = 0.75,
  stripFill = "white",
  horizontal = F,
  ...
)
```

## Arguments

- x:

  ggplot

- bgFill:

  background fill color

- lineColor:

  color of axis lines

- linesize:

  border line size

- stripFill:

  strip background color

- horizontal:

  Logical, use if you want the y axis gridlines removed

## Value

ggplot with agData theme
