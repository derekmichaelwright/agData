# theme_agData_col.

ggplot theme.

## Usage

``` r
theme_agData_col(
  x,
  bgFill = "white",
  lineColor = "grey90",
  lineSize = 0.75,
  stripFill = "white",
  horizontal = F,
  caption.adj = 1,
  caption.size = 7,
  ...
)
```

## Arguments

- x:

  ggplot

- bgFill:

  background fill color

- lineColor:

  color of axis lines

- lineSize:

  border line size

- stripFill:

  strip background color

- horizontal:

  Logical, use if you want the y axis gridlines removed

- caption.adj:

  hjust for the caption

- caption.size:

  size of the caption

## Value

ggplot with agData theme
